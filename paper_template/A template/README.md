# A‑类国赛数学建模论文模板
## 目录介绍
此文件夹存放A类（优化问题、微分方程类）竞赛文档：
1. `A‑paper‑template.docx`：日常编辑的Word原版模板；
2. `A‑paper‑template.pdf`：导出PDF，用于项目展示。

## 标准写作框架
1. 摘要（200‑300字）：研究背景‑选用模型‑求解方式‑得出结果‑模型可靠性
2. 关键词：3‑5个关键词，分号隔开
3. 问题重述：概括题目内容，禁止照搬原题文本
4. 问题分析：确定模型类型、数据预处理方法、Python对应求解库
5. 模型假设：列出合理简化条件
6. 符号说明：采用标准三线表，包含符号、说明、单位
7. 模型建立与求解：书写公式、目标函数、约束条件，正文只写核心思路，完整代码放入附录
8. 灵敏度分析：修改参数，验证模型稳定性
9. 模型的优缺点与改进方向
10. 参考文献、附录（存放全部Python代码）

## 格式规范
1. Word设置：A4纸张，正文宋体小四，1.5倍行距；标题黑体；英文变量使用Times New Roman；
2. 三线表：仅保留顶线、表头线、底线，去掉竖线；表注在表格上方，图注置于图片下方。
